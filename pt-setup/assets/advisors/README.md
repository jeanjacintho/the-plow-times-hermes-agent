# Bundled advisors

Each advisor is one Markdown file named for that person. Runtime discovery reads every `*.md`
except `README.md`; no advisor receives an application-code special case. Front matter names the
advisor, domain, and sources. The body contains limits, questions that change the advice, the
advisor's framework, and short sourced words that a recommendation may quote.

Owner-added advisors use the same one-file shape in
`~/Plow/wiki/projects/theplowtimes/advisors/`.
